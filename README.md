# Ferns-and-petal-analysis - 
Tools :  MYSQL Workbench and Power BI 
-  Built a normalized 3-table schema (Customers, Orders, Products) in MySQL Workbench using EER; loaded 100 customers, 1,000 orders, and 70 products across 7 categories and 86 cities

-  Cleaned and standardized data using ALTER TABLE; enforced data types and fixed dates with STR_TO_DATE(), handling bulk updates
  
-	Created a unified VIEW (fernpet) using INNER JOINs for combined analysis

-	Performed SQL analysis (CTEs,GROUP BY) to answer 9 business questions including ₹35.2L revenue, delivery time, top products, and sales trends

-	Connected MySQL to Power BI via ODBC and built dashboards for revenue, top cities, category splits, and occasion insights
