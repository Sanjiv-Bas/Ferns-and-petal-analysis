# Ferns-and-petal-analysis
Built a normalized 3-table MySQL database with 100 customers, 1,000 orders, and 70 products across 7 categories and 86 cities. Cleaned data using ALTER TABLE and STR_TO_DATE(), created a joined VIEW for analysis, solved business queries using CTEs and GROUP BY, and connected MySQL with Power BI dashboards for revenue, sales, and category insights.
